# Job Data Scraping & Visualization (Learning Project)

このリポジトリは、求人サイト（リクナビNEXT）から特定キーワードで検索した求人データをスクレイピングし、  
その後のデータクレンジングや可視化を一連の流れで試した学習用プロジェクトです。  
クラウドソーシング案件における **スクレイピング実装のポートフォリオ** として公開しています。

---

## 実行フロー

1. **データ取得 (Scraping)**
   - Python + BeautifulSoup4 を使用してリクナビNEXTの検索結果ページから求人データを取得
   - CSV ファイルとして出力（取得件数：約130件）

2. **データ格納 (Storage)**
   - 出力した CSV を手動で PostgreSQL にロード  

3. **データクレンジング**
   - **SQL による整形**  
     - 勤務地（都道府県など）の正規化  
     - 給与情報の表記揺れ処理  
   - **Python による整形**  
     - 必須スキルの標準化  
     - ワードマッピングを作成し、類似ワードを統一（例：`Python3` → `Python`）

4. **可視化 (Visualization)**
   - PostgreSQL と Metabase を接続
   - 簡易的なダッシュボードを作成  
     - 求人数の分布（勤務地別・給与レンジ別）  
     - 必須スキルの頻度分析
